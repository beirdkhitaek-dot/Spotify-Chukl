# Spotify Chukl
Shows the song you play on Spotify as a HUD in Minecraft (Fabric 1.21.11, works on Zalith).

- `android-app/` - phone app v1.3.0. Reads what Spotify plays and shares it on this phone only.
- `spotify-chukl-mod/` - Minecraft mod v1.9.1 (the HUD).

Setup: install the app, turn on Device Broadcast Status in Spotify, play a song, start Minecraft. The HUD appears by itself.
